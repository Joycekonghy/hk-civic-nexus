# Hong Kong CES Subject Website

## Overview
Build a polished bilingual subject website for Citizenship, Economics and Society, using the uploaded school crest and the selected Victoria Harbour editorial style. The site will be one cohesive scrolling experience with clear navigation to five content areas.

## Pages and content
- **Home:** Bilingual subject introduction, school identity, and featured links to the latest activities.
- **Panel Members:** Five named teachers, with Ms. Tsang identified as Panel Head and each represented by an original anime-inspired abstract symbol.
- **Excursions:** Five photo-ready editorial entries with clear image placeholders, titles, dates, and short descriptions that can be replaced later.
- **Awards:** A clean honours display with editable sample entries.
- **Implementation:** Present the supplied philosophy on applying knowledge, student contributions to scholarly magazines and NGO videos, plus external accolades. Include a dedicated Purposes section covering the school ethos and the supplied Curriculum Emphasis text about truth, leadership, zeal, wisdom, modesty, empathy, originality, optimism, and responsibility.

## Design direction
- Victoria Harbour palette: warm white, harbour navy, teal, and signal red.
- Libre Baskerville headings with IBM Plex Sans body text, including suitable Chinese font fallbacks.
- Editorial magazine composition with strong headlines, ruled dividers, asymmetrical story blocks, and subtle Hong Kong visual cues.
- Restrained interaction: smooth section transitions, active navigation, gentle reveals, image-placeholder interactions, and a compact mobile menu.
- Original geometric “sorcery” emblems for panel members, avoiding direct copyrighted character likenesses.

## Technical details
- Build the five requested areas as dedicated routes with shared navigation and footer.
- Add route-specific titles, descriptions, Open Graph metadata, and accessible semantic headings.
- Store the uploaded crest as a project image asset and use it in the header and home page.
- Use reusable layout, member, excursion, award, and curriculum components.
- Ensure keyboard accessibility and polished layouts across mobile and desktop sizes.
- Verify all routes, links, menus, and visible layouts in the browser.
